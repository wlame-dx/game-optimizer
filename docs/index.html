Game Optimizer

A lightweight and reversible game launcher that applies limited, temporary Windows optimizations and restores the previous state after the game exits.

View on GitHub Read the README

Reversible

Registry and power-plan values are backed up before temporary changes.

Focused

Scans Steam and Epic Games titles and launches them from a simple CLI.

Honest

No guaranteed FPS claims. Results depend on hardware, drivers, and the game.

How it works

  1. Install with install.ps1.
  2. Select a detected game.
  3. Temporary settings are applied.
  4. Close the game normally.
  5. Previous settings are restored.

Safety

The project does not overclock hardware, disable security software, or delete files. Use the source code and review changes before running scripts.

VirusTotal

No scan result is claimed until the exact release archive is uploaded and scanned. Add the public report URL to the README after scanning.
